# 🛠️ Tecnologias

- Python
- Jupyter Notebook
- Bibliotecas: NumPy, Pandas, Matplotlib e SymPy

# 📁 Como clonar

- Abra o VSCode
- Pressione ``Ctrl + ` `` ou vá em `View > Terminal` para abrir o terminal
- Digite:

```bash
git clone https://github.com/mariasaldanhaa/calculo-numerico.git
```

# ▶️ Como executar

- Instale as bibliotecas:

```bash
pip install numpy pandas matplotlib sympy jupyter
```

- Abra os notebooks (`.ipynb`) pelo VSCode ou com o comando `jupyter notebook`.
